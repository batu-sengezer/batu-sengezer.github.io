Projects

I like to work on machine learning systems deployed on real, resource-constrained hardware where every design choice has a measurable cost in memory, latency, and power, and where getting a model to run is only the first step toward understanding what it actually costs to run it well.

Edge AI Across the Compute Spectrum

The three tiers below are not independent projects, rather they form a single effort to deploy and measure the same machine-learning workload across the full hardware compute spectrum, from a Microcontroller, to an Embedded GPU, to a General-Purpose PC. The project is organized into three compute tiers: Tier 1 (MCU), Tier 2 (Embedded GPU), and Tier 3 (General-Purpose Computer/MacBook).

Compute Tier 1 - Microcontroller
Completed

Deploying a quantized (INT8) neural network on an STM32F407 microcontroller running FreeRTOS, with inference timing measured at cycle-level accuracy to establish real-time guarantees on the most resource-constrained tier of the spectrum.

Compute Tier 2 - Embedded GPU
Completed

Running the same workload on a Jetson Orin Nano to characterize GPU-accelerated inference at the edge, examining the trade-off between throughput and latency under real power and thermal constraints.
